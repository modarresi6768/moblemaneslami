# Islamic Furniture Showcase

من می‌خواهم یک وب‌سایت حرفه‌ای، مدرن، لوکس و کاملاً RTL برای یک فروشگاه با نام «مبلمان اسلامی» طراحی و اجرا کنی.



مهم:

- من یک نمونه بصری واقعی و قابل مشاهده می‌خواهم.

- فقط درباره طراحی توضیح نده؛ خود وب‌سایت را بساز و Live Preview قابل مشاهده ارائه کن.

- هیچ سؤال یا درخواست اطلاعات اضافی از من نپرس.

- اگر اطلاعاتی مثل شماره تلفن، آدرس یا تصاویر واقعی نداریم، از Placeholder حرفه‌ای استفاده کن.

- ساختار را ساده‌سازی یا حذف نکن.

- طراحی باید برای Desktop، Tablet و Mobile کاملاً Responsive باشد.

- زبان تمام رابط کاربری فارسی باشد.

- جهت کلی سایت RTL باشد.

- ظاهر سایت باید حرفه‌ای، قابل استفاده و مناسب تبدیل شدن به سایت واقعی وردپرس/Elementor Pro باشد.
